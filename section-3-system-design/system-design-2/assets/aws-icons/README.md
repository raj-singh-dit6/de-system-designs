# AWS Architecture Icons

The SVG files in this directory are the official AWS Architecture Icons used
by `../../architecture-diagram.html`. They include AWS service icons and the
AWS Account, VPC, and Private Subnet group icons. They are a selected subset
of the AWS Architecture Icons package, downloaded from the [AWS Architecture
Icons page](https://aws.amazon.com/architecture/icons/).

The icon package is released by AWS on a quarterly cadence. Refresh these
assets from the official source when updating the architecture diagram.
